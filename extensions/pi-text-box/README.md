# pi-statusline (editor only)

Rounded editor text box for pi. No footer, no commands — always on.

```text
╭─────────────────────────────╮
│ › type here…                │
╰────────────────────── my task ──╯
```

- Rounded box with `╭─╮`, `│ │`, `╰─╯`
- Accent `›` prompt
- Session name on the bottom-right border (`/name …`)
