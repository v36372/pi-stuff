# pi-statusline (editor only)

Rounded editor text box for pi. No footer, no commands — always on.

```text
╭─────────────────────────────╮
│ › type here…                │
╰──────────── Claude Opus 4.8 (high) ──╯
```

- Rounded box with `╭─╮`, `│ │`, `╰─╯`
- Accent `›` prompt
- Active model name and thinking level on the bottom-right border
- Updates immediately after model or thinking-level changes
